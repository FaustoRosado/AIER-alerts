6. 🔄 End-to-End Workflow Validation
Definition: Demonstrate that the system works as intended across components.
Examples by project type:
DevSecOps:
* Commit triggers pipeline → security scans (Trivy, Checkov) pass → container built and pushed to ECR → deployed to ECS/EKS staging → smoke tests pass → Slack notification sent
Security Lab:
* Student requests lab → Lambda triggers IaC deployment → isolated VPC with vulnerable instances created → student accesses via Cognito-authenticated portal → EventBridge schedules teardown after 4 hours → Lambda destroys resources
SOC:
* CloudTrail logs unauthorized API call → GuardDuty detects threat → finding sent to Security Hub → EventBridge triggers Lambda → Lambda enriches alert and creates PagerDuty ticket → analyst views in OpenSearch dashboard → Step Functions orchestrates containment (isolate instance via security group)
SIEM:
* VPC Flow Logs → Kinesis Firehose → S3 → Lambda parses logs → OpenSearch indexes → correlation rule detects port scan → alert fires → Splunk/Wazuh receives enriched alert → analyst investigates via dashboard
KMS:
* Application requests secret from Secrets Manager → Secrets Manager decrypts using KMS CMK → secret returned to application → S3 bucket enforces encryption with KMS key → RDS database encrypted at rest with CMK → CloudTrail logs all KMS API calls
Complete the following:
* Workflow Description: What you validated in Sprint 2
* Test Cases (2–3): Name, steps, expected result, actual result
   * Example: "Test Case 1: GuardDuty Finding to Wazuh Integration"
      * Steps: Simulate unauthorized API call, verify GuardDuty detection, confirm Wazuh receives finding
      * Expected: Alert appears in Wazuh dashboard within 5 minutes
      * Actual: Alert received in 3 minutes; screenshot attached
* Evidence: Screenshots/logs linked to each test case
* Issues & Resolution: Blockers encountered and how you resolved or will address in Sprint 3
   * Example: "Wazuh agent installation failed on Amazon Linux 2023; resolved by updating agent version to 4.7"
Tip: Keep tests repeatable and commit test scripts/artifacts to GitHub where possible.
